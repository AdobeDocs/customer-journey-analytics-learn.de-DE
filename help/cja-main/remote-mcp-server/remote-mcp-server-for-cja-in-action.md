# Remote-MCP-Server für [!DNL Customer Journey Analytics] in Aktion

Erfahren Sie, wie Sie KI-Tools wie Claude, ChatGPT oder Cursor mit dem Adobe Customer Journey Analytics (CJA) MCP-Server verbinden, um Datenansichten zu untersuchen, Berichte auszuführen und KPI-Einblicke für Führungskräfte mit natürlicher Sprache zu generieren. In dieser Demo wird gezeigt, wie Remote-MCP-Server skalierbare, gesteuerte Analytics-Workflows und automatisierte Berichte in Adobe Experience Platform ermöglichen.

Weitere Informationen finden Sie in der [Dokumentation](https://developer.adobe.com/analytics-mcp/docs/cja/){target="_blank"} zu Content Analytics.
