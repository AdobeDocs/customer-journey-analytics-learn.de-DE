# Remote-MCP-Server für [!DNL Customer Journey Analytics] Übersicht

Erfahren Sie, wie Sie KI-Tools wie [!DNL Claude], [!DNL ChatGPT] oder [!DNL Cursor] mit dem MCP-Server von Adobe Customer Journey Analytics (CJA) verbinden, um Datenansichten zu durchsuchen, Berichte auszuführen und KPI-Einblicke für Führungskräfte mithilfe natürlicher Sprache zu generieren. In dieser Demo wird gezeigt, wie Remote-MCP-Server skalierbare, gesteuerte Analytics-Workflows und automatisierte Berichte in Adobe Experience Platform ermöglichen.

Weitere Informationen finden Sie in der [Dokumentation](https://developer.adobe.com/analytics-mcp/docs/cja/){target="_blank"} zu Content Analytics.
